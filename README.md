# Honeypot Lab

## Overview

This project demonstrates the deployment and monitoring of a honeypot in a controlled lab environment. The objective is to capture and analyze unauthorized connection attempts and malicious activity for security monitoring and learning purposes.

## Objectives

* Deploy a honeypot in a virtualized environment.
* Capture attacker interactions and connection attempts.
* Monitor and analyze generated logs.
* Understand common attack patterns targeting exposed services.

## Technologies Used

* Kali Linux
* Virtual Machine Environment
* Honeypot Software
* Linux Command Line

## Project Workflow

1. Create a virtual machine for the honeypot.
2. Configure network connectivity.
3. Deploy and start the honeypot service.
4. Generate test attack traffic.
5. Collect and review logs.
6. Analyze attacker behavior and connection attempts.

## Learning Outcomes

* Honeypot deployment and configuration.
* Log analysis and monitoring.
* Understanding attack reconnaissance techniques.
* Security Operations Center (SOC) monitoring concepts.
